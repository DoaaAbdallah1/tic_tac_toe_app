# Tic Tac Toe

A two-player Tic Tac Toe game built with Flutter.

The game brings the classic X and O experience to mobile, with a simple interface, score tracking, and a time challenge that makes each round more engaging.

## Gameplay

- Play against another player on the same device.
- Take turns placing X and O on a 3×3 board.
- The first player to reach **3 points** wins the match.
- Each round has a 30-second timer.
- Keep track of both players' scores.
- Restart and play again whenever you want.

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/DoaaAbdallah1/tic_tac_toe_app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd tic_tac_toe_app
   ```

3. Install the dependencies:

   ```bash
   flutter pub get
   ```

4. Run the app:

   ```bash
   flutter run
   ```
